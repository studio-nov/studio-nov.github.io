# Redirecciones QR — Nova Studios

Uso interno de Operaciones. Cada QR impreso apunta a una dirección de este sitio
(por ejemplo /f07/), que abre el formulario de reporte de aseo, mantenimiento y daños.

**Para cambiar a dónde lleva un QR:** edita solo `links.txt`.
No borres ni renombres las carpetas, ni los archivos `404.html`, `index.html` o `.nojekyll`.
